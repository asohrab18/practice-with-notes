1. Basic Setup

[1.1] Install Git: https://git-scm.com/downloads

[1.2] Configure user info:
git config --global user.name "Sohrab Alam"
git config --global user.email "sohrab.alam86@gmail.com"

[1.3] Check version:
git --version

_______________________________________________________________________________________________________________________

2. Core Git Workflow

[2.1] Clone a repository:
git clone <repo-url>

For example: 
git clone https://github.com/asohrab18/Microservices


[2.2] Command to know the actual location of repository in my system:
pwd

Output: /c/Users/ULTRA/loggers-repo


[2.3] Check repository status:
git status


[2.4] Add changes:
git add <file>   # single file
git add .        # all changes


[2.5] Commit changes:
git commit -m "Your commit message"

For example:
git commit -m "Java9 allows private methods."

[2.6] Push changes to remote:
git push origin <branch-name>

For example:
git push origin main


[2.7] Pull latest changes from remote:
git pull origin <branch-name>

_______________________________________________________________________________________________________________________

3. Branching (Essential for Java projects)

[3.1] Create a new branch:
git checkout -b feature/my-feature


[3.2] Switch branches:
git checkout main

[3.3] Merge branch:
git merge feature/my-feature

_______________________________________________________________________________________________________________________

4. Undo mistakes safely

[4.1] Unstage a file:
git reset HEAD <file>

[4.2] Discard local changes:
git checkout -- <file>

[4.3] Revert a commit:
git revert <commit-hash>

_______________________________________________________________________________________________________________________

5. Best practices

[5.1] Commit often with meaningful messages.

[5.2] Pull before pushing to avoid conflicts.

[5.3] Use branches for features or bug fixes.

[5.4] Learn to read Git logs:
git log --oneline --graph --all
